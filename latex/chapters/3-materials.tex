In MCNP each nuclide is identified by a ZAID of the form $ZZZAAA.nnX$, whose numerical part is built from the atomic number $Z$ and the mass number $A$ as

\begin{equation}
ZZZAAA = 1000\,Z + A.
\end{equation}

For example $92235$ stands for $Z=92$ and $A=235$, that is U-235, while $8016$ stands for oxygen-16.
The suffix $.nnX$ names the cross-section evaluation, here the continuous-energy libraries $.50c$, $.51c$ and $.55c$.

The value following each ZAID is the fraction of that nuclide in the material.
A positive value is an atom fraction and a negative value is a weight fraction.
